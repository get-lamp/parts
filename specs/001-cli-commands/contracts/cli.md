# CLI Commands

## Show X part
    > <part_X_identifier>

## List categories and parts related to X category
    > <category_X_identifier>

## Add X units TO part.qty
    > <part_x_identifier> + X

## Subtract X units from part.qty
    > <part_x_identifier> - X

## add category or part
    > add cat | part

## help, quit, q, exit...
    Work as expected.
