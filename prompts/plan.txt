COMMANDS

# Show X part
    > <part_X_identifier> : print the part data

# List categories and parts related to X category
    > <category_X_identifier>

    Print the category path (if this category has ancestor categories, show the path as
    cat0/cat1/catn...) and list all categories having this category as parent and parts related to this category branch.

# Add X units from part.qty
    > <part_x_identifier> + X

# Subtract X units from part.qty
    > <part_x_identifier> - X

# add category or part
    > add cat | part

    Present the user with a simple form

    IF PART
    identifier: <text input>
    qty: <int input>
    package: <selector: DIP, SOP, ... (default to DIP)> (this needs to be included in parts model)
    pins: <int input> (this needs to be included in parts model)
    datasheet: <url or filepath. If URL is a downloadable PDF file, download to datasheet folder and populate this field with the new filepath>
    description: <text input>
    category: <text input with autocomplete from categories. If unknown, category is inserted>

    IF CATEGORY
    identifier: <text input>
    category: <text input with autocomplete from categories. If unknown, category is inserted>

# help, quit, q, exit...
    Work as expected.


AUTOCOMPLETE

On user input in prompt, an autocomplete calls parts.api and gets the appropriate possible continuations, according to
the grammar on parts.parser
